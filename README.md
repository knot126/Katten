# Katten Project

Katten is a reverse engineering, documentation and attempt at a full reimplementation of the server software for the *Touch Pets* series of games. It is also a partial reimplementation for games which require or use the Plus+ network, and is enough to bypass the required login in games like *Topple 2*, *Rolando* and *Rolando 2: Quest for the Golden Orchid*.

## Why?

Despite that these games were shut down over 10 years ago on 31 March 2013, those who remember these games would still like to play them again. Touch Pets and Plus+ games are also intresting from a historical perspecitive, since they were not only some of the earliest mobile games but also some of the first to move to a free-to-play model.
