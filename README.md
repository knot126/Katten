# Katten Project

Katten is a reverse engineering, documentation and attempt at a full reimplementation of the server software for the *Touch Pets* series of games. It is also a partial reimplementation for games which require or use the Plus+ network.

Despite that these games were shut down over 10 years ago on 31 March 2013, we would still like to play them again.
